## 便宜的代价在哪里

### root 给你，责任也给你

RackNerd 的 VPS 是非托管型（unmanaged）。官方页面写明每个套餐含完整 root 权限，ctrl 控制面板负责开关机、重装系统、HTML5 VNC 控制台、一键应用、网络防火墙、重置 root 密码和在线升级。系统更新、软件安装、防火墙规则、凭据管理、数据备份全在用户这边。

这套分工在便宜 VPS 里是通行做法。Virtarix 在产品页上把自管定义得很清楚：你管理 Linux 操作系统、已装软件、更新、防火墙配置、凭据和恢复副本。买之前想清楚愿不愿意干这些活，比对比参数更重要。

### CPU 是共享的，内存和硬盘不是

VPSDime 在自己的产品页上写得很直白：内存和磁盘完全独享，CPU 与同一台宿主上的其他 VPS 共享，靠自动化监控调度保障峰值。便宜 VPS 基本都遵循这个模式，RackNerd 的特价档也没有承诺独占核心。

这条对选档的影响很实际。跑编译、视频转码、爬虫并发这类吃满 CPU 的任务，1 vCore 的机器会明显拖；需要稳定算力的场景应该直接看 6 GB（6 核）或 8 GB（7 核）档，而不是指望低档位扛住。

### 流量给的是明确数字

RackNerd 每档都标了固定月流量，1 GB 档 3 TB，8 GB 档 20 TB，不是"不限量"。行业里对带宽的写法差别很大：Virtarix 写 unlimited bandwidth subject to service limits（不限流量但受服务限制约束），Arct Cloud 只对出站流量计费、入站免费，HOSTKEY 入站免费（公平使用政策）、出站按套餐和机房计。三种口径没法直接比大小。

RackNerd 这种写法对读者最友好，额度是硬数字，超了会怎样在条款里查得到。建站主要消耗出站带宽，3 TB 对日访问几千 IP 的博客绰绰有余，真要担心的是被刷流量或者做下载站。

### 备份要自己安排

RackNerd 的服务条款写明不对数据完整性负责，机器出故障时官方不赔数据。便宜 VPS 里备份通常单独收费：Arct Cloud 的每日自动备份按月费的 20% 计费，手动快照 $0.04/GB/月；Virtarix 每个 VPS 送 1 个快照，同时提醒用户另外保留独立副本。

稳妥做法是每周把网站文件和数据库导到本地或对象存储，成本几乎为零，恢复时也不用等工单。
